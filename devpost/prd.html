Weppy — Sales pipeline pribadi via Telegram & web

Bot publik dan aplikasi web; data tiap private chat atau sesi browser terisolasi dari pengguna lain.

Perjalanan pengguna

1. Mulai
/start di Telegram atau buka /app → onboarding bahasa (default Inggris), nama, jam WIB
2. Lapor
Teks atau voice note (Telegram atau rekam di browser) → Groq ekstraksi/transkripsi
3. Lengkapi
Kartu empat field → klarifikasi satu per satu + Skip
4. Tindak lanjuti
Rekap, pengingat, detail, CSV pribadi

Setiap operasi data memakai pemilik chat_id Telegram atau token sesi web (web:<token>).

Perilaku dan penerimaan

Isolasi pengguna
  • Profil, catatan, dan draf tersimpan per private chat atau sesi browser.
  • Greeting/recap/export hanya membaca catatan pemilik.
  • Callback detail dengan ID pengguna lain menghasilkan “not found”.
  • Dua sesi web tidak saling melihat catatan.
Laporan dan klarifikasi
  • Teks/voice note menjadi kartu empat field; fakta tak disebut tetap kosong.
  • Field kurang ditanya satu per satu; jawaban/Skip hanya memperbarui draf pemilik.
  • Voice note gagal meminta input ulang/teks.
Web
  • Landing di /, chat di /app, dengan kartu catatan, aksi cepat, panel pipeline, dialog pengaturan, dan unduh CSV.
  • Sesi disimpan di localStorage; mulai sesi baru = data baru.
Jadwal dan hosting
  • Cron menjadwalkan rekap/pengingat per profil Telegram dalam zona Asia/Jakarta.
  • Sesi web tidak menerima push terjadwal; rekap diminta dari aplikasi.
  • Hosting gratis best-effort, bukan jaminan uptime 24/7 atau SLA.

Boundary

Tidak termasuk grup Telegram, berbagi catatan, akses tim, dashboard analitik, akun/kata sandi web, transport WhatsApp, atau SLA produksi. Hindari data pelanggan sensitif pada layanan demo gratis.
