Asisten Sales WhatsApp B2B

Asisten WhatsApp pribadi untuk sales B2B yang mengubah voice note/teks setelah kunjungan menjadi catatan pipeline yang rapi, lalu membantu follow-up dan rekap harian.

Scope bilang "agent mengekstrak 4 info dan bertanya yang kurang dengan Skip." Sekarang kita tahu persis artinya: onboarding singkat (nama + bahasa + jam rekap) saat pertama pakai, histori bawaan WhatsApp + balasan rekap saat disapa, kirim voice note (unduh cepat + transkripsi), terima kartu teks berisi 4 field + status, dilengkapi lewat chat satu per satu dengan Skip (quick-reply), tanggal follow-up ditentukan agent, dan rekap sore via template ter-approve + perintah demo.

1 · Diagram perjalanan (klik langkahnya)

2 · Permukaan: cuma 1 thread chat + 1 layar laporan

Thread chat utama
  • Histori bawaan WhatsApp; rekap via balasan saat disapa
  • Tengah: laporan baru + balasan agent
  • Bawah: kirim voice/teks + tombol Skip (maks 3, judul ≤20)
Kartu laporan teks
  • Pesan teks terformat di dalam chat, bukan Flows/webview
  • Hanya untuk melihat + instruksi lanjut di chat
  • Tanpa ketuk-buka-tutup

Nada: singkat, praktis, membantu — bukan formulir CRM. Selalu ada Skip. Dua bahasa ID/EN ikut profil. Bebas hanya 24 jam; di luar itu wajib template.

3 · Perilaku per bagian (klik untuk kriteria cek)

0. Onboarding: nama + bahasa + jam rekap (baru)
  • Pemakaian pertama: agent bertanya nama panggilan, bahasa (Indonesia/Inggris), dan jam rekap sore, satu per satu, semuanya bisa di-skip.
  • Skip bahasa = Indonesia; skip jam = default 17:00 waktu lokal; nama dipakai untuk menyapa berikutnya.
Kartu laporan: 4 field + status
InstitusiContact + roleProduk dibahasTahap deal: belum ada
  • Kartu menampilkan 4 field dengan nilai atau penanda "belum ada" — tanpa karangan.
  • Ada cara lanjut di chat untuk melengkapi yang kurang.
Klarifikasi chat dengan Skip (cara utama)
  • Agent bertanya satu per satu, tiap pertanyaan ada opsi Skip.
  • Skip = field tetap kosong, lanjut ke berikutnya, catatan parsial tetap tersimpan + konfirmasi singkat.
Follow-up: tanggal dari agent
  • Tanggal follow-up ditentukan agent dari isi laporan dan terlihat di catatan (tampil DD Mon YYYY, simpan YYYY-MM-DD).
  • Dalam 24 jam: pesan bebas. Di luar 24 jam: template ter-approve ID/EN. Demo: cek follow-up.
Rekap sore: per tahap + follow-up besok
  • Satu pesan otomatis tiap sore di jam rekap, hanya dari nomor uji ini.
  • Otomatis = template ter-approve ID/EN (di luar 24 jam); demo rekap sekarang = pesan bebas dalam sesi.
Dua bahasa: Indonesia + Inggris (baru)
  • Voice/teks dua bahasa dipahami sebagai satu alur yang sama.
  • Balasan mengikuti bahasa pilihan onboarding; ganti kapan saja via chat ("ganti ke bahasa Inggris" / "switch to Indonesian").
Histori saat buka + laporan via voice/teks
  • Histori = bawaan WhatsApp; rekap diberikan saat sales menyapa; pengguna baru dipicu pesan pertama → sambutan + contoh.
  • Voice note (unduh cepat ~5 mnt + transkripsi) dan teks diperlakukan sebagai satu jenis laporan yang sama.

4 · Keadaan penting (states)

  • Pertama pakai / kosong — sambutan + onboarding singkat (nama, jam rekap) + contoh laporan, bukan error.
  • Parsial — kartu tandai yang kosong, masuk klarifikasi Skip.
  • Audio tidak jelas — tidak dikarang; agent minta klarifikasi bagian yang kurang jelas.
  • Di-skip — tetap disimpan sebagai parsial.
  • Tersimpan — 4 field + tanggal follow-up bertahan antar sesi.
  • Batas — 1 sales, 1 nomor uji (allowlist), mode uji coba. Bebas 24 jam; di luar itu template ID/EN. Media ~5 menit.

5 · Yang dibangun vs ditunda

Membangun (POC)
  • Onboarding (nama + bahasa + jam)
  • Dua bahasa ID/EN
  • Histori + rekap saat buka
  • Voice + teks satu alur
  • Kartu 4 field + status
  • Chat Skip + simpan parsial
  • Klarifikasi audio tak jelas
  • Tanggal FU dari agent + pengingat
  • Rekap sore per tahap
Ditunda
  • Edit form di Flows
  • Banyak sales / tim / banyak nomor
  • CRM produksi, dashboard, kalender

Keputusan produk

  • Input tetap voice/teks (voice → transkripsi); kartu hanya teks, bukan Flows — cepat di lapangan.
  • Dua bahasa via pilihan eksplisit saat onboarding, bisa diganti via chat — mudah ditebak dan didemokan.
  • Chat Skip jadi cara utama; form ditunda agar muat 2–4 jam.
  • Tanggal FU dari agent (DD Mon YYYY / YYYY-MM-DD); rekap fokus aksi besok via template.

Pertanyaan terbuka

  • Nama + parameter 4 template ID/EN di dashboard Meta — diputuskan saat build.
  • Format tanggal sudah diputuskan — tampil DD Mon YYYY, simpan YYYY-MM-DD.
