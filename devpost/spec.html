6 · Disederhanakan, risiko, keputusan

DisederhanakanKenapa
Kartu teks + tombol, bukan FlowsFlows butuh layar + endpoint ekstra (±1–2 jam). Kernel tetap terbukti.
JSON lokal, bukan DB server1 sales, <100 catatan; file bisa dibuka langsung buat belajar.
Jadwal + perintah demo (rekap sekarang)Tidak bisa nunggu sore saat rekaman; fungsi yang sama.
Lokal + README, tanpa deploySubmission hanya wajib video + repo.
Risiko nyata: (1) tunnel mati/URL berubah → update Callback URL, tes ping; (2) di luar 24 jam tanpa template APPROVED → gagal kirim; pastikan 4 template ID/EN APPROVED; (3) media ~5 mnt → unduh segera; (4) Groq limit/lambat → balas "coba lagi 1 menit", jangan simpan setengah; (5) VN tidak jelas → minta ulangi, jangan karang kartu; (6) token WA kedaluwarsa → generate baru di Meta Developer.
Ketidakpastianmu (webhook lokal → WA): laptop tak punya alamat publik → ngrok memberi alamat sementara yang meneruskan ketukan Meta ke localhost:5000. Verifikasi kecil saat build: kirim ping, lihat log app.py + balasan pong. Diam = masalah tunnel/URL, bukan AI.
Belum diverifikasi (cek awal build): nama model Groq aktif, versi Graph API, format audio VN, rate limit gratis.
